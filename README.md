# L.o.S.A.

Windows 10/11 desktop launcher prototype, version 0.10.8.

## 0.10.8 — Mod Center and Bedrock foundation
- Added an interactive Modrinth catalogue for Java mods and modpacks with search, game-version and loader filters.
- Added a separate Bedrock hub for add-ons, resource packs, worlds and its own compatibility workflow; Bedrock is not treated as a Java loader.
- Replaced the cosmetics category “Накидки” with “Плащи” in the shop and workshop.
- Catalogue browsing is live; installing files into instances, dependency resolution and the Bedrock installer remain follow-up implementation work and are not represented as complete.
- 0.10.7 is the base branch; this draft does not change main and must not be merged without the owner's approval.
