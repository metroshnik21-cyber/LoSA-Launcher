# L.o.S.A. — Linux Demo

Демонстрационная версия L.o.S.A. для Linux, предназначенная для показа интерфейса проекта.

## Что доступно
- Главный экран и библиотека сборок с тестовыми профилями.
- Друзья и серверы с демонстрационными данными.
- Витрина косметики: плащи, питомцы, ауры и головные уборы.
- Настройка акцентного цвета с предпросмотром.
- Настройки и справка.

Игровой запуск, подключение к серверам, покупки, Microsoft-вход и загрузка игровых файлов отключены. Пароли не запрашиваются.

## Скачать
После успешной сборки откройте GitHub → Actions → L.o.S.A. Linux Demo → последний успешный запуск и скачайте артефакт LOSA-Linux-Demo-AppImage.

## Запуск
1. Скачайте файл .AppImage.
2. В свойствах файла разрешите выполнение как программы (или выполните chmod +x имя-файла.AppImage).
3. Запустите файл двойным щелчком.

Для некоторых дистрибутивов может потребоваться поддержка FUSE 2.
